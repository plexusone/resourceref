## [v0.1.0] - 2026-11-08 ([`f0d0ba3`](https://github.com/plexusone/resourceref/commit/f0d0ba3))

### Highlights

- Initial release: ResourceRef, a canonical and comparable RFC 3986 resource reference that passes owner-canonical URIs (ARN, SPIFFE, HTTPS, URN) through untouched, and the scheme engine for defining owned URI schemes as data

### Added

- Stdlib-only module scaffolding with Go CI, lint and CodeQL workflows, under the Apache-2.0 license ([`e3d48ac`](https://github.com/plexusone/resourceref/commit/e3d48ac))
- ResourceRef: Parse, String, Equal and text/JSON marshaling as a plain string, with conservative RFC 3986 canonicalization (case, percent-encoding, dot segments), an external-URI passthrough corpus and fuzz tests for canonical-form idempotence ([`bec6e9b`](https://github.com/plexusone/resourceref/commit/bec6e9b))
- scheme.Profile format and Load: URI subset constraints, authority registry, path shapes, resource-type registries and version/alias grammar, with a JSON Schema generated from the Go types and embedded in the schema package ([`c02e3f3`](https://github.com/plexusone/resourceref/commit/c02e3f3))
- Profile.Validate and Profile.Split: match a ResourceRef against a profile and return its typed Parts (authority, app, org, resourceType, id, version), with a reference test profile and golden corpus ([`6a8ff79`](https://github.com/plexusone/resourceref/commit/6a8ff79))

### Documentation

- docs/embedding.md: how to add a resource-reference field to an IR, in Go and in hand-written or generated JSON Schema, and how to keep logical and instance identity apart ([`269e06c`](https://github.com/plexusone/resourceref/commit/269e06c))
- README, package docs and specs use neutral placeholder names in every example ([`f0d0ba3`](https://github.com/plexusone/resourceref/commit/f0d0ba3))
