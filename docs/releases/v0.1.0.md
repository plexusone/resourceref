# v0.1.0 — 2026-11-08

The initial release of `resourceref`: universal resource references and a
data-driven engine for owned URI schemes, for Go.

## Highlights

A resource reference is a URI. `ResourceRef` parses any absolute URI once,
holds it in canonical form, and compares and marshals it as a plain string.
Owner-canonical references such as AWS ARNs, SPIFFE IDs, GitHub URLs and URNs
pass through untouched. The `scheme` package defines owned URI schemes as
data, so a namespace owner can publish its own scheme as a profile document
rather than code.

## Added

- **`ResourceRef`**: `Parse`, `String`, `Equal`, and text/JSON marshaling as
  a plain string. Canonicalization is conservative: it lowercases the scheme
  and host, normalizes percent-encoding (RFC 3986 §6.2.2.2) and removes dot
  segments (§5.2.4), and never reinterprets a scheme's own semantics. The
  zero value is invalid and errors on marshal.
- **Fuzz-tested canonical form**: canonical form is a fixed point, so
  parsing a canonical reference returns it unchanged.
- **`scheme.Profile` and `scheme.Load`**: a SPIFFE-strict URI subset, an
  authority registry, ordered path shapes, opt-in resource-type registries
  and an `@version` / `@alias` suffix grammar. `Load` validates a profile's
  structure, including regexes, shapes and authority cross-references.
- **`Profile.Validate` and `Profile.Split`**: check a `ResourceRef` against a
  profile and return its typed `Parts` (authority, app, org, resource type,
  ID, version).
- **`schema`**: the JSON Schema for the profile format, generated from the
  Go types, and an embeddable schema fragment for a `ResourceRef` field.

The module's runtime has no dependencies outside the standard library.
